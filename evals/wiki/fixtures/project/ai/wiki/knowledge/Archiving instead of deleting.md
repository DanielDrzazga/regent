# Archiving instead of deleting

A [[Note]] is never deleted. Archiving takes it off the list, but it can be restored.

## Why

A customer support Consultant must be able to restore a Note at the [[User]]'s request for up to
2 years. A deleted Note would be lost together with what the User asks for.
